# TIDELINE

An independent, quiet ocean experience. English, no accounts, no commerce, no analytics. Built with Vite, TypeScript and custom CSS. No runtime server required.

## Local development

Node.js 22.12+ or 24. Run `npm ci`, then `npm run dev`. `npm run build` type-checks and produces dist. `npm run preview` previews the production build.

## Deployment

Enable GitHub Pages with GitHub Actions. Push main to run the included deployment. Relative asset paths support the repository subpath. Each nature website is a separate repository.

## Experience

Native scrolling, four distinct chapters, optional original Web Audio score, a global pause-motion control, reduced-motion support, keyboard navigation. Audio starts only on explicit request and pauses when the tab is hidden. No external audio download or generation subscription.
